说明：每个组件都是你独享的一套容器（独立网络 / 独立端口 / 独立数据），与其他同学互不影响。 点击卡片上的「启动」即可创建；端口徽章中带 ↗ 的可在浏览器直接打开。
组件依赖：启动 Spark / Hive / HBase 时，系统会自动先启动 Hadoop 等前置组件（Hive 还需 MySQL、Kafka 需 ZooKeeper、Flume 需 Kafka）， 已运行的依赖会自动跳过，无需手动按顺序点。当前使用 standard 还是 HA 版 Hadoop 由服务器 config/environment.conf 决定。
进入容器：运行中的容器右侧有 >_ 终端 按钮，点击可在浏览器里执行 docker exec 命令（只能进入你自己的容器）。
控制台出现 Found orphan containers 警告属正常现象：同一用户的多个组件共用一个 Compose 项目名，以便服务名互相解析；它不会删除别的组件。
